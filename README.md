# My Midterm Project Code

My mid term project code is supposed be a graphical user interfaced resistor calculator. It is meant to calculate the resistance of a 4 band resistor. The color that the user chooses for each band will be documented by the 4 band inputs. Then the code will verify the color of each input and calculate the resistance with the tolerance. The code will then ask if the user wants to calculate the resistance of another four banded resistor. If the user says yes, the code will rerun, but if the user picks no, then the code will stop.
